# مستكشف الهوية القطرية (Qatar Identity Explorer)
لعبة ويب تعليمية تفاعلية للصفين الثالث والرابع الابتدائي — مدرسة الثمامة الابتدائية للبنين، قطر.

- React + TypeScript + Tailwind CSS v4 + Framer Motion + Vite
- رسومات SVG وأصوات WebAudio مولّدة بالكود (بدون ملفات ذات حقوق)، خط Cairo (OFL) مضمّن
- `npm install` ثم `npm run dev` للتطوير، و`npm run build` للإنتاج
- المحتوى كله في `src/data/content.ts`. راجع `TEACHER_GUIDE.md`
